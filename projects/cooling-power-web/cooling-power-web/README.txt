Sitio estatico de presentacion comercial para Cooling and Power E.A.S. Unipersonal.

FUNCIONAMIENTO

1. Abra index.html con un navegador moderno.
2. Mantenga la carpeta assets junto a index.html.
3. Los botones de telefono, WhatsApp y correo abren la aplicacion correspondiente.
4. El mapa de Google necesita conexion a Internet.
5. El sitio no requiere servidor ni base de datos.
